## 🌟 What is CANDY?

**CANDY** is an LLM-powered personal desktop AI assistant designed to make computer interaction simple and natural.

Instead of manually opening applications, searching for information, or managing files, you can simply **talk to Candy** and let it perform tasks for you.

> 💬 **You Talk → Candy Understands → Candy Thinks → Candy Acts**

Candy combines **voice recognition, Large Language Models, and desktop automation** to create a smarter way to interact with your computer.

---

## 🧠 AI Brain

Candy can work with different AI models depending on your setup.

### ☁️ Google Gemini

Uses **Google Gemini** for cloud-based AI intelligence and natural-language understanding.

### 🏠 Ollama

Uses **Ollama** to run supported LLMs locally, providing an option for more private and offline AI interactions.

### 🔄 Multi-Model Approach

```text
              🎙️ Your Voice
```

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/veerlavenkamma/candy.git
```

### 2️⃣ Open the Project

```bash
cd candy
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Configure Your AI Model

Add the required API configuration according to your Gemini setup, or configure Ollama for local model usage.

### 5️⃣ Run Candy

```bash
python main.py
```

## 🔐 Privacy

Candy supports a combination of **cloud-based and local AI**.
