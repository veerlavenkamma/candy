# Candy - Your Personal Desktop AI Assistant

Candy is your personal desktop AI assistant built with Python. Just talk to it. It will open apps, find files, search websites, and do your computer work for you by listening to your voice and replying back like a real assistant.

### Features
- Voice Control: Control your desktop with voice commands.
- Local AI: Powered by Ollama for fast and private responses.
- File Management: Find and manage your files easily.
- Web Browsing: Search websites and browse the internet.
- App Automation: Open applications and perform daily tasks.
- Natural Voice Response: Replies like a real human.

### Tech Stack
- Python
- Ollama
- SpeechRecognition, pyttsx3, PyAutoGUI

### Installation
1. Clone the repo
   git clone https://github.com/veerlavenkamma/candy
2. Install packages
   pip install -r requirements.txt
3. Run Ollama
   ollama run llama3
4. Start Candy
   python main.py
